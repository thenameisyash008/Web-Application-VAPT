# Web Application Security Testing (VAPT)

This repository contains my hands-on Web Application Security Testing and Vulnerability Assessment & Penetration Testing (VAPT) projects performed in controlled lab environments for learning and educational purposes.

## Applications Tested
- DVWA (Damn Vulnerable Web Application)
- Hack Yourself First
- TestFire (Altoro Mutual)
- ZeroWebAppSecurity

## Tools Used
- Burp Suite
- Nmap
- Kali Linux
- Browser Developer Tools

## Vulnerabilities Identified
- SQL Injection (SQLi)
- Cross-Site Scripting (XSS)
- Cross-Site Request Forgery (CSRF)
- Insecure Authentication
- IDOR (Insecure Direct Object Reference)
- Security Misconfigurations

## Skills Demonstrated
- Web Application Penetration Testing
- Manual Vulnerability Assessment
- Request Manipulation
- Authentication Testing
- Security Documentation and Reporting

## Reports Included
Each project contains:
- Vulnerability Description
- Proof of Concept (PoC)
- Impact Analysis
- Risk Assessment
- Mitigation Recommendations
- Supporting Screenshots

## Disclaimer
Testing was performed only on intentionally vulnerable applications in controlled lab environments for ethical learning and educational purposes.
