# Hack Yourself First - Web Application Security Testing

## Overview
Performed Web Application Vulnerability Assessment and Penetration Testing (VAPT) on Hack Yourself First in a controlled lab environment for learning and educational purposes.

## Tools Used
- Burp Suite
- Browser Developer Tools
- Kali Linux

## Vulnerabilities Tested
- SQL Injection (SQLi)
- Cross-Site Scripting (XSS)
- CSRF
- IDOR
- Authentication Issues
- Security Misconfigurations

## Skills Demonstrated
- Web Application Penetration Testing
- Manual Vulnerability Assessment
- Request Manipulation
- Authentication Testing
- Security Documentation and Reporting

## Reports Included
- Vulnerability Description
- Proof of Concept (PoC)
- Impact Analysis
- Mitigation Recommendations
- Supporting Screenshots

## Disclaimer
Testing was performed only on intentionally vulnerable applications in controlled lab environments for ethical learning and educational purposes.
